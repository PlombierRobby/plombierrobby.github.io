# Robby Plombier — site vitrine

Site statique en HTML/CSS/JavaScript, prêt pour GitHub Pages.

## Fichiers
- `index.html` : contenu du site, métadonnées SEO et données structurées.
- `style.css` : design responsive pour ordinateur et mobile.
- `script.js` : menu mobile et année du pied de page.
- `assets/favicon.svg` : icône du site.

## Publier gratuitement avec GitHub Pages
1. Connectez-vous à https://github.com/ et créez un compte si nécessaire.
2. Cliquez sur **New repository**.
3. Nom conseillé : `robby-plombier` ; choisissez **Public**.
4. Téléversez tous les fichiers et le dossier `assets` à la racine du dépôt (pas le dossier parent).
5. Dans le dépôt, ouvrez **Settings → Pages**.
6. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Cliquez sur **Save**.
7. Attendez la publication. GitHub affichera l'adresse du site dans la section Pages, normalement sous la forme `https://VOTRE-PSEUDO.github.io/robby-plombier/`.

## Important avant publication
- Dans `index.html`, remplacez `https://VOTRE-PSEUDO.github.io/` dans la balise `canonical` par l'adresse réelle du site. Pour un dépôt de projet, utilisez l'URL complète réelle, par exemple `https://VOTRE-PSEUDO.github.io/robby-plombier/`.
- Vérifiez que le nom commercial affiché correspond bien à votre activité.
- Complétez les mentions légales requises (identité de l'éditeur, statut, coordonnées professionnelles et hébergeur). Ajoutez une page de confidentialité si vous ajoutez plus tard un formulaire ou des outils de suivi.
- Les communes affichées sont indicatives : vérifiez le rayon réel par la route et retirez celles que vous ne desservez pas.
- Ne publiez pas d'affirmations non vérifiées (urgence 24/7, tarifs fixes, certifications, assurances ou avis clients).
- Ce site ne comporte pas de formulaire : les boutons téléphone et SMS ouvrent l'application correspondante sur le mobile.

## Référencement Google
Le site contient un titre, une description, des titres hiérarchisés et des données structurées `Plumber`. Après publication :
1. Vérifiez l'adresse du site sur mobile et ordinateur.
2. Ajoutez le site à Google Search Console et demandez l'indexation de l'URL.
3. Gardez le nom, le téléphone et la zone identiques sur vos profils professionnels.
4. Les résultats Google ne sont pas instantanés et l'indexation ne peut pas être garantie.
